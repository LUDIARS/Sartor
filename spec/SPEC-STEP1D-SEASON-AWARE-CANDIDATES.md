# SPEC-STEP1D — 季節に合う服種だけを候補にする

SPEC-STEP1C で入れた細分類 (`subKind`) を使い、季節に合わない服種を提案候補から外す。

## §1 季節外の細分類を候補にしない

- 候補選定は細分類単位で季節外の商品を落とす。素材や商品名からの推測はしない。
- 除外表 (`src/domain/season-fit.ts`)
  - 春 / 秋: ダウン・中綿
  - 夏: ダウン・中綿 / コート / アウターベスト / ブルゾン / デニムジャケット / マウンテンパーカ /
    ニット / スウェット / パーカ / ブーツ
  - 冬: ポロ / T シャツ / ショートパンツ
- カーディガンは夏でも冷房対策として残す。テーラードジャケットは通年残す。
- 除外の結果その種別の候補が無くなった場合は、季節外の商品で埋めずに候補なしとして扱う
  (提案 API は従来どおり 422 `no_candidates` を返す)。

## §2 季節の決め方

- 装いのベクトルで季節が指定されていればそれを使う。
- 未指定なら実行日の月から決める (3-5 春 / 6-8 夏 / 9-11 秋 / 12-2 冬)。
- 決まった季節は LLM プロンプトにも渡し、候補が既に季節で絞られていることを明示する。
